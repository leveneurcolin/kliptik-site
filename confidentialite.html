Politique de confidentialité

Dernière mise à jour : 19 novembre 2026

AccueilConditions d’utilisationConfidentialité

Données utilisées

  • Le jeton d’accès TikTok, donné par TikTok après la connexion du titulaire du compte.
  • Les informations de base du profil (identifiant, nom affiché, photo), pour savoir sur quel compte les brouillons sont envoyés.
  • Les vidéos que le propriétaire choisit d’envoyer.

Où elles sont gardées

Uniquement sur l’ordinateur personnel du propriétaire de Kliptik. Aucun serveur Kliptik, aucune base de données en ligne, aucune publicité, aucun suivi. Ce site ne collecte rien et n’utilise pas de cookies.

Partage

Les données ne sont ni vendues ni partagées. Les vidéos ne sont envoyées qu’à TikTok, à la demande du titulaire du compte.

Suppression

Retirer l’accès dans TikTok (Paramètres > Sécurité > Applications autorisées) rend le jeton inutilisable ; le propriétaire peut aussi effacer le jeton gardé sur son ordinateur à tout moment.

Contact

Par la page du projet : github.com/leveneurcolin/kliptik-site.

English

Data used: the TikTok access token, basic profile info (ID, display name, avatar) and the videos the owner chooses to upload. Storage: only on the owner’s personal computer; no Kliptik server, no online database, no ads, no tracking; this website collects nothing and uses no cookies. Sharing: data is never sold or shared; videos are only sent to TikTok at the account holder’s request. Deletion: revoke access in TikTok (Settings > Security > Authorized apps); the owner can delete the locally stored token at any time. Contact: via the project page linked above.
